# Учебная платформа для подбора лекторов

Одностраничное веб-приложение (SPA) для подбора профессиональных лекторов, спикеров и тренеров. Платформа соединяет компании, образовательные учреждения и НКО с экспертами в различных областях знаний.

Проект разработан в рамках лабораторной работы по дисциплине «Проектирование пользовательских интерфейсов».

## 📋 О проекте

Приложение реализует учебную платформу, которая предоставляет онлайн и офлайн услуги по преподаванию дисциплин для физических и юридических лиц.

Основные возможности:
- Каталог лекторов с подробной информацией: образование, стаж, учёная степень
- Полный перечень преподаваемых дисциплин и тем
- Прозрачные тарифы на занятия
- Информация о партнёрах платформы
- Отзывы клиентов и раздел FAQ

Дизайн приложения повторяет предоставленный макет: сине-серая цветовая гамма, градиент в шапке, сетка карточек лекторов.

## 🗂️ Данные и роутинг

### Где лежат данные

Все данные о лекторах хранятся в одном файле:

**`src/data/lecturersData.js`**

Это массив объектов `lecturersData`, где каждый объект описывает одного лектора:

```javascript
{
  id: 1,
  name: "Петров Дмитрий Сергеевич",
  gender: "male",
  photo: "https://...",           // ссылка на фото из облака
  education: "МФТИ, ...",
  experience: "12 лет",
  degree: "кандидат технических наук",
  disciplines: [                  // массив дисциплин
    {
      title: "Алгоритмы и структуры данных",
      description: "изучаем, как эффективно...",
      topics: ["Введение в анализ сложности", "..."]  // список тем
    }
  ],
  tariffs: [                      // массив тарифов
    { type: "Индивидуальное занятие (60 мин)", price: "2500 ₽" },
    { type: "Пакет из 8 занятий", price: "18 000 ₽" }
  ]
}
```

### Где лежит роутинг

Приложение является **одностраничным (SPA)** и **не использует React Router** или другой клиентский роутинг — все секции расположены на одной странице последовательно в компоненте `App.jsx`.

Навигация между секциями реализована через **якорные ссылки (anchor links)** в шапке сайта:

```jsx
<a href="#about">О нас</a>
<a href="#lecturers">Лекторы</a>
<a href="#reviews">Отзывы</a>
<a href="#faq">FAQ</a>
```

Каждая секция имеет соответствующий `id`:

| Ссылка в хедере | `id` секции | Компонент |
|---|---|---|
| `#home` | `home` | `HeroSection` |
| `#partners` | `partners` | `PartnersSection` |
| `#about` | `about` | `AboutSection` |
| `#lecturers` | `lecturers` | секция в `App.jsx` |
| `#how-it-works` | `how-it-works` | `HowItWorksSection` |
| `#reviews` | `reviews` | `ReviewsSection` |
| `#faq` | `faq` | `FaqSection` |

Плавная прокрутка обеспечивается CSS-правилом `scroll-behavior: smooth;` в `index.css`.

### Хранение фотографий

Фотографии лекторов размещены в облачном хранилище и подгружаются по прямым ссылкам в поле photo.
В случае недоступности изображения предусмотрен fallback — компонент LecturerCard подменяет битую ссылку на заглушку через обработчик onError.
